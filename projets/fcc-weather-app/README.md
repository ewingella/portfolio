# Weather App

Application météo en temps réel développée dans le cadre de la formation **FreeCodeCamp - JavaScript Algorithms and Data Structures**.

## 🎯 Objectifs du projet

- Intégrer une API météo tierce
- Utiliser l'API de géolocalisation du navigateur
- Gérer les requêtes asynchrones avec fetch()
- Créer une interface utilisateur moderne et responsive

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Geolocation API
- Weather API

## 📋 Fonctionnalités

- Récupération des données météo en temps réel
- Géolocalisation automatique de l'utilisateur
- Recherche de ville manuelle
- Affichage des prévisions météorologiques
- Interface responsive

## 🚀 Démarrage

Ouvrir le fichier `index.html` dans un navigateur moderne.
