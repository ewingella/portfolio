# Survey Form

> Projet de certification FreeCodeCamp - Responsive Web Design

## 📋 Description

Premier projet de certification FreeCodeCamp. Création d'un formulaire d'enquête responsive qui respecte toutes les user stories et bonnes pratiques d'accessibilité.

## 🎯 User Stories FreeCodeCamp

1. **User Story #1:** Je peux voir un titre avec `id="title"` en taille H1
2. **User Story #2:** Je peux voir une courte explication avec `id="description"` en taille P
3. **User Story #3:** Je peux voir un formulaire avec `id="survey-form"`
4. **User Story #4:** Dans le formulaire, je peux entrer mon nom dans un champ avec `id="name"` et `type="text"`
5. **User Story #5:** Dans le formulaire, je peux entrer mon email dans un champ avec `id="email"`
6. **User Story #6:** Si j'entre un email invalide, je vois une erreur de validation HTML5
7. **User Story #7:** Dans le formulaire, je peux entrer un nombre dans un champ avec `id="number"`
8. **User Story #8:** Le champ nombre ne doit pas accepter de valeurs non-numériques
9. **User Story #9:** Je peux voir des placeholders pour les champs name, email et number
10. **User Story #10:** Je peux voir un select dropdown avec `id="dropdown"`
11. **User Story #11:** Je peux sélectionner une option dans un groupe de radio buttons avec `name="user-recommend"`
12. **User Story #12:** Je peux sélectionner plusieurs checkboxes avec une classe commune
13. **User Story #13:** Je peux voir un textarea pour des commentaires additionnels
14. **User Story #14:** Je peux voir un bouton de soumission avec `id="submit"`

## 🛠️ Technologies utilisées

- HTML5 (structure et validation)
- CSS3 (design et responsive)
- Flexbox/Grid pour la mise en page

## ✨ Fonctionnalités

- Formulaire entièrement responsive (mobile-first)
- Validation HTML5 native
- Design moderne avec dégradés
- Accessibilité optimisée
- Labels associés à tous les champs
- Messages d'erreur clairs

## 📚 Objectifs d'apprentissage

- Créer des formulaires HTML5 sémantiques
- Utiliser les différents types d'input (text, email, number, radio, checkbox)
- Implémenter la validation HTML5
- Structurer un formulaire accessible
- Appliquer un design responsive

## 🚀 Comment utiliser

1. Ouvrir `index.html` dans un navigateur
2. Remplir le formulaire avec vos informations
3. Valider pour voir la validation en action
