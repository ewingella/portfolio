# Number Guesser

## Description
Projet de jeu interactif de devinettes de nombres développé dans le cadre du module "Building Interactive Websites" de Codecademy.

## Objectifs du projet
- Créer un jeu interactif où l'utilisateur doit deviner un nombre
- Mettre en pratique la manipulation du DOM avec JavaScript
- Implémenter la logique de jeu et la validation des entrées
- Développer une interface utilisateur engageante

## Technologies utilisées
- **HTML** : Structure de la page
- **CSS** : Styles et mise en page
- **JavaScript** : Logique de jeu et interactivité

## Structure du projet
```
number-guesser/
├── index.html      # Page principale
├── style.css       # Styles CSS
├── script.js       # JavaScript principal
├── game.js         # Logique du jeu
├── metadata.json   # Métadonnées du projet
└── README.md       # Documentation
```

## Fonctionnalités prévues

## Installation et utilisation
1. Cloner le repository
2. Ouvrir `index.html` dans un navigateur
3. Commencer à jouer !

## Apprentissages
Ce projet permet de pratiquer :
- La manipulation du DOM
- La gestion des événements JavaScript
- Les structures conditionnelles
- Les fonctions et la logique de programmation
- L'expérience utilisateur interactive
