# 🏆 fCC Forum Leaderboard

Tableau de classement du forum FreeCodeCamp avec données API - Projet FreeCodeCamp JavaScript Algorithms and Data Structures.

## 📋 Description

Cette application affiche un tableau de classement des contributeurs les plus actifs du forum FreeCodeCamp en récupérant les données depuis l'API officielle.

## ✨ Fonctionnalités à implémenter

- 📊 **Récupération de données API** : Fetch des données du forum fCC
- 📈 **Tableau de classement** : Affichage trié par activité
- 🔍 **Filtrage** : Filtrer par catégorie ou période
- 🎨 **Interface dynamique** : Mise à jour en temps réel
- ⚠️ **Gestion d'erreurs** : Messages d'erreur conviviaux

## 🛠️ Technologies utilisées

- **HTML5** : Structure de la page
- **CSS3** : Design et responsive
- **JavaScript** : Logique et manipulation de données
- **Fetch API** : Récupération de données asynchrones
- **DOM Manipulation** : Affichage dynamique

## 🎯 Objectifs d'apprentissage

Ce projet permet de pratiquer :

1. **Fetch API** :
   - Requêtes HTTP avec fetch()
   - Gestion des promesses (.then() / async await)
   - Parsing de données JSON

2. **Manipulation de données** :
   - Tri et filtrage d'arrays
   - Transformation de données
   - Calculs et agrégations

3. **DOM dynamique** :
   - Création d'éléments HTML
   - Mise à jour de contenu
   - Gestion des états (loading, error, success)

4. **Gestion d'erreurs** :
   - try/catch avec async/await
   - .catch() avec promesses
   - Affichage d'erreurs utilisateur
