# 🔢 Sorting Visualizer

Visualiseur d'algorithmes de tri avec animations interactives - Projet FreeCodeCamp JavaScript Algorithms and Data Structures.

## 📋 Description

Cette application permet de visualiser le fonctionnement de différents algorithmes de tri en temps réel avec des animations colorées et interactives.

## ✨ Fonctionnalités à implémenter

- 📊 **Visualisation d'algorithmes** : Bubble Sort, Quick Sort, Merge Sort, Insertion Sort, etc.
- 🎬 **Animations en temps réel** : Voir chaque étape de l'algorithme
- ⚡ **Contrôle de vitesse** : Ajuster la vitesse d'animation
- 🎲 **Génération aléatoire** : Créer de nouveaux tableaux de données
- 📈 **Comparaison de performances** : Compter les comparaisons et swaps

## 🛠️ Technologies utilisées

- **HTML5** : Structure de la page
- **CSS3** : Design et animations
- **JavaScript** : Implémentation des algorithmes et animations
- **DOM Manipulation** : Mise à jour dynamique de l'interface
- **Algorithms** : Algorithmes de tri classiques

## 🎯 Objectifs d'apprentissage

Ce projet permet de pratiquer :

1. **Algorithmes de tri** :
   - Bubble Sort, Selection Sort, Insertion Sort
   - Quick Sort, Merge Sort
   - Comprendre la complexité temporelle (Big O)

2. **Animations JavaScript** :
   - Utiliser setTimeout pour créer des animations
   - Gérer l'asynchrone avec async/await
   - Contrôler la vitesse d'exécution

3. **Manipulation du DOM** :
   - Créer et modifier des éléments HTML dynamiquement
   - Appliquer des styles CSS via JavaScript
   - Gérer les événements utilisateur

4. **Gestion d'état** :
   - Suivre l'état du tri en cours
   - Désactiver/activer les contrôles pendant l'animation
   - Compter les opérations

## 🎨 Algorithmes à implémenter

### Algorithmes de base
- **Bubble Sort** : Comparaisons adjacentes et échanges
- **Selection Sort** : Sélection du minimum à chaque itération
- **Insertion Sort** : Insertion dans la partie triée

### Algorithmes avancés
- **Merge Sort** : Diviser pour régner (recursif)
- **Quick Sort** : Partition autour d'un pivot
- **Heap Sort** : Utilisation d'un tas
