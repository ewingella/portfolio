# Component Library++

Solo project du **Frontend Path** de Scrimba - module **Learn React**.

## 🎯 Objectif

Créer une bibliothèque de composants React réutilisables.

## 🚀 Lancer le projet

```bash
npm install
npm run dev
```

## 📁 Structure

```
src/
├── components/    # Composants React réutilisables
├── hooks/         # Custom hooks
├── App.jsx        # Composant racine
├── App.css        # Styles de l'app
├── index.css      # Reset et styles globaux
└── main.jsx       # Point d'entrée React
```

## 🛠️ Technologies

- React 18
- Vite
- JavaScript ES6+
- CSS3
