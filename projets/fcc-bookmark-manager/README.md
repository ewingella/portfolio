# 📚 Bookmark Manager App

Application de gestion de favoris avec sauvegarde locale - Projet FreeCodeCamp JavaScript Algorithms and Data Structures.

## 📋 Description

Cette application permet de gérer une collection de favoris web avec une interface moderne et intuitive. Les données sont sauvegardées localement dans le navigateur grâce à localStorage.

## ✨ Fonctionnalités à implémenter

- ➕ **Ajout de favoris** : Enregistrez vos sites favoris avec un nom et une URL
- 🗑️ **Suppression** : Retirez les favoris dont vous n'avez plus besoin
- 💾 **Sauvegarde locale** : Les données persistent entre les sessions grâce à localStorage
- ✅ **Validation d'URL** : Vérification automatique de la validité des URLs
- 🎨 **Interface moderne** : Design responsive avec dégradés et animations
- 🔗 **Accès rapide** : Ouvrez vos favoris dans un nouvel onglet

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Design moderne avec variables CSS et animations
- **JavaScript** : Manipulation du DOM et localStorage
- **Web APIs** : URL validation et localStorage

## 🎯 Objectifs d'apprentissage

Ce projet permet de pratiquer :

1. **Manipulation du DOM** :
   - Sélection d'éléments avec getElementById
   - Création dynamique d'éléments
   - Gestion d'événements (submit, click)

2. **LocalStorage** :
   - Sauvegarde de données structurées (JSON)
   - Récupération et parsing des données
   - Persistance entre les sessions

3. **Validation de données** :
   - Validation d'URLs avec l'API URL
   - Vérification de champs vide
   - Détection de doublons

4. **Gestion d'état** :
   - CRUD complet (Create, Read, Update, Delete)
   - Synchronisation entre données et interface
   - Réactivité de l'interface
